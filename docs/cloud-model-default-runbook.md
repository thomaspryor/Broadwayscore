# Model default and escalation (BRO-8289)

Routine sessions run on Sonnet 5.5: `.claude/settings.json` sets `"model": "claude-sonnet-5-5"`, workers get it from `node scripts/session-model.js`, and `review-panelist` runs on Sonnet. Opus stays for P0, architecture or plan-review-tier work, CLAUDE.md §18 shared infrastructure and scoring logic. To escalate: start the child with `model` set to Opus plus `MODEL-REASON:` (runbook above), or switch a running session with `/model opus`. Fable is not used by default.
Quality guard (owner condition): `node scripts/model-quality-scorecard.js` compares the 28 days before 2026-11-25 with the days since (rework, extra land attempts, reverts, reopened cards, cost per landed card); it prints OK, WORSE or INSUFFICIENT DATA and exits 0 / 1 / 3. Rechecks: BRO cards stamped RECHECK-AFTER 2026-12-09 and 2026-12-23. Rollback if WORSE: delete the `model` key (and `_comment_model`) in `.claude/settings.json`, set `review-panelist` and its line in `tests/unit/claude-agent-models.test.mjs` back to `claude-opus-5-5`; keep the scorecard. Note the settings key also reaches Mac and headless `claude` runs that pass no `--model`.
