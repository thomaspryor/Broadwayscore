# Starting a worker session from a cloud session (BRO-5040)

Moved out of `.claude/CLOUD.md` (BRO-7315) so it is read before `create_session`, not by every session. The steps are unchanged.

1. File or claim the card first; it carries the handoff and a safe-form `VERIFY:` line. File it `--child "BRO-N: <short>"` (BRO-6359): In Progress and claimed, so no worker takes it (`--dispatch` gets built twice). If `create_session` fails, move it back to Todo.
2. **Model (BRO-5228/6684):** pass `model` from `node scripts/session-model.js BRO-N ...` (`--no-card`: none; and `opus-budget.js --help`); a hook re-checks Opus. Mixed batch: Sonnet; Opus cards go to an Opus subagent.
3. `create_session` with `source_url: "https://github.com/thomaspryor/Broadwayscore"` (exact), `title: "BRO-N: <short>"`, `tags: ["bro-n"]` and a standalone prompt: the card id and what done means; claim via `linear-session.js claim`; worktree via `git worktree add`, never `EnterWorktree`; land via `land/<name>`, follow the run, re-run VERIFY on main, close it; a line `BUDGET: <1-12>h` (usually 6h): then it lands, reports, ends; a line `REPORT-BACK:`: last, `mcp__claude-code-remote__send_message` `@parent` "REPORT-BACK BRO-N:" outcome, run URL (never `SendMessage`); never call `create_session`, `send_later`, `create_trigger`; never end a turn waiting on CI or its jobs: poll in-turn or hand them to a workflow; if a skill is "Unknown", follow `.claude/commands/<name>.md`.
4. Tell the owner in one line what you started.
5. Need its result? Before ending a turn, background-run `node scripts/lib/child-idle-watch.js watch --session <id>` per child, Bash timeout: 7200000 (BRO-6717, BRO-7109). On wake, save `get_session` JSON, run `child-idle-watch.js check --from-json <f>`, do what it prints. Silent at BUDGET+30 min: `send_message` it to wrap up; never `interrupt_session` mid-land.
6. **Once it runs and owns the work end to end, SAFE TO ARCHIVE is fine** (BRO-5881): it lands and verifies its own work. If you must act on its result, or the change is high-risk, end `KEEP OPEN — <what you wait on>` with the step 5 watch (BRO-6020); say in plain words what it is doing and your next step.
