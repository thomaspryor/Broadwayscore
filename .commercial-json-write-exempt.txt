# Allowlist for the commercial.json direct-write lint (test.yml / pre-push).
#
# Format: one line per script: filename followed by `--` and a one-line reason.
# Lines starting with `#` are comments. Trailing whitespace is trimmed.
#
# Background: `data/commercial.json` used to be written by 31 scripts each
# doing their own fs.readFileSync/fs.writeFileSync pair with no coordination —
# concurrent writers could silently clobber each other's changes (same class
# of bug as shows.json — see the "generalize shows-write-guard.js" card).
# All writers now route through scripts/lib/commercial-write-guard.js, which
# adds a file lock plus a re-read-and-merge-by-slug step before writing.
#
# New scripts cannot join this list — the lint blocks them. Only add an
# entry here for a script that genuinely writes a DIFFERENT commercial.json-
# shaped file (e.g. a scratch/checkout copy outside data/commercial.json)
# where the lock wouldn't apply anyway, with a one-line reason.

merge-commercial-conflict.js -- git-conflict-resolution tool invoked by push-with-retry.sh; operates on git-checkout'd --ours/--theirs sides and does its own custom per-slug merge (mergeCommercialJson) rather than the guard's re-read-and-merge, so routing it through the guard would double-merge against a mid-checkout working tree.
