description: Opening night broadcasts only go out for Broadway and West End shows — never Off-Broadway or Off-West End
type: feedback
archived: true

Opening night email broadcasts are only sent for Broadway and West End shows. Off-Broadway and Off-West End shows do not get broadcasts.

**Why:** OB/OWE shows have smaller audiences and lower subscriber interest; broadcasts are reserved for the main markets.

**How to apply:** When checking broadcast readiness (morning-radar.js, orchestrator, opening-night pipeline), treat OB/OWE broadcast status as n/a. Don't flag missing broadcasts for these markets.
