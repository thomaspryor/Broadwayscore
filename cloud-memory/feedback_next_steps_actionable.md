---
name: Keep going — don't stop to list "next steps" you could do now
description: "If you CAN do the next step, DO it — don't list it as future work."
type: feedback
---

**Rule:** Never output a "next steps" list that includes things you can do right now. This includes labeling them "genuinely future sessions" — that label is almost always wrong.

**Why:** User is non-technical and on phone. Every time you list something actionable as a "next step," they have to read it, decide it's doable, and tell you to go do it. This has happened in 5+ sessions. It's lazy delegation disguised as helpfulness.

**The test — apply BEFORE writing any "next steps":**
For each item, ask: "Is this blocked by something outside my control RIGHT NOW?"
- Needs user to make a decision between options? → Stop and ask.
- Needs credentials/access I don't have? → List it.
- Needs a different repo checked out? → List it.
- Would push the session past ~2 hours? → List it.
- Everything else? → **Just do it. Don't list it. Don't announce it. Do it.**

**Anti-pattern to catch:** "I finished the main task, here are follow-ups" — if the follow-ups are natural continuations (rebuild, deploy, fix adjacent issues found during the work), they're part of the task, not next steps.

**How to apply:** When you feel the urge to write "Next steps:", stop. Run the test above on each item. Do every item that passes. Only list the remainder, if any.
