The structuredTips in theater-metadata.json were generated by `scripts/generate-theater-tips.js` using Gemini Flash. Despite the prompt saying "don't invent names," it freely generated false accessibility claims (elevator access for theaters without elevators).

**Why:** The prompt only prohibited inventing restaurant/garage names but gave the LLM free rein on seating advice and accessibility claims. LLMs treat absence of information as permission to fill in plausible-sounding facts.

**How to apply:** Never let an LLM generate factual/safety-critical claims (accessibility, ADA compliance, physical infrastructure). Source these from official websites only. For any LLM-generated content going to production, add a verification step that cross-checks verifiable claims against authoritative sources. The verified `accessibility` object in theater-metadata.json is the source of truth — structuredTips accessibility text should be derived from it, not generated independently.
