# Allowlist for the reviews.json direct-write lint (test.yml).
#
# Format: one line per script: filename followed by `--` and a one-line reason.
# Lines starting with `#` are comments. Trailing whitespace is trimmed.
#
# Background: the `data/reviews.json` file is a derived aggregate produced by
# `scripts/rebuild-all-reviews.js`. New scripts MUST NOT write to it directly —
# they should modify the source-of-truth files in `data/review-texts/<showId>/`
# and let the rebuild produce the aggregate. Any script that writes
# reviews.json raw bypasses the rebuild's audit trail (rebuild-score-drift,
# rebuild-regression, opening-night-completeness) and ships data quality
# issues with no breadcrumb.
#
# This allowlist exists for the historical violators that pre-date this gate
# (mostly one-off fix scripts from 2024-2025). New scripts cannot join this
# list — the lint blocks them. Each existing entry should eventually be
# migrated (modify source review-texts files + trigger rebuild) and removed
# from the list.

# === Canonical writer (the rebuild itself) ===
rebuild-all-reviews.js -- canonical writer for data/reviews.json (the rebuild target itself)
